# Readiness — Prototipo interattivo

Prototipo navigabile dell'app **Readiness**: preparazione professionale a colloqui, talk e presentazioni.

**Prova dal telefono:** https://ragno236.github.io/readiness-prototype/

- 63 schermate navigabili (frecce in alto o pulsanti in-app)
- Ottimizzato per iPhone: da Safari, tocca **Condividi → Aggiungi a schermata Home** per lo schermo intero
- File unico autosufficiente (`index.html`), nessuna build necessaria
